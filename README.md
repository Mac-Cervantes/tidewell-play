# Tidewell (play build)

A cozy low-poly harbor sim. Play: https://mac-cervantes.github.io/tidewell-play/

On iPhone: open the link in Safari → Share → Add to Home Screen.

This repo only holds the built game; it is copied here by `tools/deploy-play.sh` from the main (private) repo.
